四、校验、预演与入库

前置条件：接收上述工程文件，按项目后端说明配置 Python、依赖和 PostgreSQL。
使用已激活的后端虚拟环境，在仓库 backend 目录执行命令。
先在接收方测试库验证，再切换到实际目标库；目标库配置沿用现有工程方式。
以下 <资料包>、<报告目录> 和 <管理员ID> 都替换成接收方自己的值。

0. 确认当前数据库，只输出库名和地址，不输出口令：
   python manage.py shell -c "from django.db import connection; print({k: connection.settings_dict[k] for k in ('ENGINE','NAME','HOST','PORT')})"
   python manage.py migrate

1. 文件校验，不写数据库、不访问赛事网站：
   python manage.py import_curated_competitions "<资料包>/导入清单.json" --report "<报告目录>/文件校验.json"
   预期：catalog=116、competitions=125、resources=143、documents=393。
   该命令会检查结构、编码、引用、附件路径及原件哈希。

2. 获取有权限的现有管理员ID，进行事务预演：
   python manage.py import_curated_competitions "<资料包>/导入清单.json" --actor-id <管理员ID> --preview --report "<报告目录>/预演.json"
   预演会执行数据库校验，结束时回滚全部写入。
   操作者需 active、staff，以及 curation.add_importrun、curation.add_knowledgedocument、
   competitions.add_competition、competitions.change_competition、
   competitions.add_competitionsource、resources.add_resource、resources.change_resource 权限。
   不沿用本机验收账号ID；该账号已停用，数据库ID也不具备跨环境含义。

3. 记录本次草稿入库确认。
   随包导入清单的review仍为pending，直接使用--apply会被现有导入命令拒绝。
   本机旧“本地验收导入清单.json”只授权过本机验收，不用于其他数据库。
   接收方确认本次导入范围和目标库后，在资料包同一目录另存“导入执行清单.json”，
   仅把其review填写为：
       {"status":"approved","reviewed_by":"实际确认人","reviewed_on":"实际确认日期YYYY-MM-DD"}
   这是此次草稿入库操作的确认，不等同于所有事实核验完毕或公开发布批准。
   不修改赛事正文、来源、稳定编码和package_id；事实维护源仍是整理底稿.json。

4. 对确认后的执行清单再次预演，再正式导入：
   python manage.py import_curated_competitions "<资料包>/导入执行清单.json" --actor-id <管理员ID> --preview --report "<报告目录>/执行预演.json"
   python manage.py import_curated_competitions "<资料包>/导入执行清单.json" --actor-id <管理员ID> --apply --report "<报告目录>/入库结果.json"
   全部成功后再次预演，同一批数据应报告unchanged，且不新增正文版本。

不指定--batch时处理全部116项；也可按五批选择：
--batch 1：131—155；--batch 2：156—180；--batch 3：181—205；
--batch 4：206—230；--batch 5：231—255。--batch可重复指定。
每次命令在一个事务中执行；异常回滚该次命令，不会回滚此前已成功的其他批次。
--preview和--apply互斥。失败时先查看报告；人工修改冲突沿用现有处理，不强行覆盖。
本命令当前仅接受131—255，前130项后续由对应负责人的交付另行接入。

五、写进哪些表、以后怎样使用

CatalogEntry：目录身份、2026目录年份、等级、责任学院。
Competition、CompetitionSource、CatalogBinding：实际届次、参赛规则、报名、来源及目录关联。
Resource及关联：学习资源、介绍、链接；稳定编码复用同一资源。
KnowledgeDocument、DocumentRevision、DocumentLink：整理正文、来源定位、附件路径/哈希、
适用届次及版本关联。学习导读可直接关联目录，不凭空关联到全部历史届次。
ImportRun、ImportedObject、ImportedObjectRevision：操作记录、幂等识别及更新历史。
DocumentReview：具体正文版本的审核记录，供以后公开检索使用。

赛事、资源和知识正文初始为草稿，recruitment_enabled=False。
版本metadata.package_root记录本次导入文件所在绝对目录，附件使用相对路径。
部署后必须持久保存资料包；移动资料包前安排根路径迁移，不能留下失效附件。
日后页面和AI接入这些表时，再按现有发布规则选择可公开的内容。
student_visible_documents()会排除未审核正文以及关联的草稿/下架内容。
本次未新增公开HTTP接口、向量库、模型调用或聊天界面。
