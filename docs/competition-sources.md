# 赛事来源

更新日期：2026-09-28。当前范围以 `backend/competition_catalog/data/tongji-2026.json` 中的 **255 项同济 2026 本科生学科竞赛目录**为准，包含理工、人文社科、艺术设计和外语等全部学科。目录依据见[学校发布页](https://qdc.tongji.edu.cn/info/1035/1791.htm)。逐项官网、实际结果与失败类型见[采集覆盖表](competition-catalog-coverage.md)，验证和运行状态见[团队进度](progress.md)。

## 三类数据

| 数据 | 保存内容 | 当前用途 |
| --- | --- | --- |
| 学校目录 | 编号、原名、年份、目录等级、赛事级别及责任学院，不含教师姓名或工号 | 确定收录范围；保留学校原分类，不自行判断“含金量” |
| 官网入口与原文 | 经核对的赛事官网、主办方通知或校内官方通知，附官网关联依据、域名白名单、正文版本与运行状态 | 持续保存到后台，供后续提取与核对；不直接生成公开赛事卡 |
| 结构化赛事 | 有明确来源的赛事届次、资格、人数、日期与报名入口 | 经现有适配器校验和受控采纳后供前端读取 |

学校目录有 255 项，不表示已找到 255 个独立官网，也不表示全部完成抓取或已经公开。多个赛项可能共用官网；部分只有公众号、动态页面、登录系统或附件。未找到可靠入口的条目保留待核实，不猜域名，不把聚合站当官网。

学校目录归属与具体子赛奖项认定不同。目录等级按原文件保存；某主题赛属于目录赛事系列，不据此推断加分、保研资格或当年校内报名安排。

## 官网监测

执行 `init_competition_catalog` 登记目录及已核对入口，再由 `sync_competition_catalog` 轮询启用且到期的官网。通用监测保存标题、正文、附件链接、明确发布日期及版本；附件目前仅记链接，不自动解析 PDF、图片、Word 或压缩包。

官网入口必须有来源证据。其他学校转发的通知可用于确认官网网址，不能把其校内报名截止、名额或选拔条件套给同济。赛事专站与主办机构综合站分别处理；只在已核对域名内跟随相关通知，不根据网页外链自行扩大白名单。

年次、届次和赛项须区分：官网换成 2027 届时，不把新规则写成目录中的 2026 届；同一总赛下个人赛与团队赛不共用人数、报名截止。抓取失败、动态页面和访问验证记录为异常，原文没有的信息保持缺项。
