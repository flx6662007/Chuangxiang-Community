## 校验

在本目录执行 `python verify_package.py`。Excel 由 Artifact Tool 生成，日期为可排序日期值，空日期表示原文未注明；链接列为可复制地址，HTML 阅读页提供可点击链接。

`文件清单.json` 保存相对路径、原始字节 SHA-256；UTF-8 文本另保存去 BOM、将 CRLF/CR 统一为 LF 后的 SHA-256，保留末尾换行。二进制使用原始字节。两个文件清单自身不参与哈希以避免循环依赖；ZIP 校验文件在本目录的上一级。
