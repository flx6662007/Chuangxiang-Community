# 组队页面验收

日期：2026-09-26。使用独立 PostgreSQL 测试库、两个已核验的普通测试账号及一条明确标注“隔离验收”的构造赛事，在 `localhost:5174` 操作实际 Vue 页面，经代理访问独立 Django 后端。所有登录均通过页面密码表单和真实 Session/CSRF 流程完成，未使用 `force_authenticate` 代替浏览器登录。

## 已执行结果

| 操作 | 实际页面结果 |
| --- | --- |
| 招募者填写固定模板、预览并发布，刷新详情 | 版本 1、剩余 1 人；刷新后仍存在，实际到期时间明确 |
| 申请人提交申请 | 进入“待处理”；此时无联系方式入口 |
| 招募者接受并开放联系 | 可查看申请人的测试联系方式；名额仍为 1 |
| 招募者先单方确认 | 显示招募者已确认、申请人未确认，尚未正式入队 |
| 招募者修改每周投入 | 卡片升到版本 2，到期时间不延长；申请挂起，显示具体变更，双方确认均清除 |
| 申请人按新条件继续并确认 | 申请资料升到版本 2；仍需招募者重新确认 |
| 招募者再次确认 | 申请成为“已正式入队”；队伍出现双方成员，名额从 1 变为 0 |
| 成员发起退出 | 显示固定 24 小时回应截止时间，成员关系及占用名额仍保留 |
| 招募者同意退出 | 显示退出时间和已同意记录；名额从 0 恢复为 1 |
| 双方重新查看申请 | 联系方式入口均消失；退出成员的队伍页仅保留本人历史，不展示另一成员 |
| 查看通知并标记一条已读 | 可见接受、条件变更、双方确认和退出结果通知；标记后未读状态消失 |

所检查标签页未记录 JavaScript error/warn。验收发现已结束退出请求仍显示“待我回应”，现已修为“回应方为本人”；前端现有 20 项测试及生产构建通过。

修正后的“回应方为本人”已在招募者页面核实。验收结束后已退出测试账号、关闭临时页面、停止测试端口并删除专名临时数据库；正常网站的后端、前端和结算任务继续运行。
