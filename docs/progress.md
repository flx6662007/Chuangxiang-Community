# 团队进度

**记录日期：2026-09-25。** 本文件统一记录三人共享成果。代码实现、本机验证、上传、合并和公网部署分别记录，不用百分比代替可检查的交付。

## 当前结论

第一轮的赛事浏览与内容管理、第二轮的账号与学校邮箱核验已完成本地实现。PostgreSQL 独立测试库完整测试 **148 项通过**，前端 **12 项测试及构建通过**，本机浏览器核心操作已验证。

当前先做**无需购买服务的开发版**：本机运行，控制台读取验证码，AI 默认关闭。本轮没有购买服务器、域名或模型服务，没有向真实学校邮箱发信，也未公网部署。后续资源准备见 [部署说明](deployment.md) 与 [资源清单](procurement.md)。

## 接下来做什么

| 顺序 | 主负责人 | 工作与完成标准 |
| --- | --- | --- |
| 1 | 全队 | 按 [人工验收](manual-checks.md) 启动各自环境，验证赛事浏览、邮箱验证码、联系方式和密码找回；记录无法复现的步骤 |
| 2 | 后端，数据库配合 | 依据已确认模型实现固定模板招募、申请及入队事务；检查邮箱、联系方式、限制、赛事有效性、重复申请和名额并发 |
| 3 | 前端，后端配合 | 开发招募卡、发布表单、申请/处理界面；使用已约定错误和状态，与后端一起验收完整流程 |
| 4 | 后端，数据库配合 | 接续赛事下架对已有队伍的影响、通知与审计，解除当前关联队伍下架保护前先完成状态测试 |
| 5 | 团队共同确定内容负责人 | 确认可接入官方来源和公众号同步方式，建立来源更新、去重及管理员确认流程，再接入真实内容 |
| 6 | 后端牵头，前端/数据库配合 | 用授权样本评测通知提取与快讯草稿，记录准确性、漏项、耗时及费用；确认后才启用模型 |
| 7 | 团队协调资源 | 优先申请学校服务器、子域名、发件服务；确需付费时按资源清单确认后采购，完成目标服务器和真实收件验收后开放 |

本轮“免费”指无需新增购买服务，仍需成员投入开发维护时间。当前不必买 GPU、托管数据库、对象存储或 CDN。科研、快讯、资源、收藏、通知与治理等后续模块按功能逐步实现，不把完整模型表一次性开放为公共写接口。
