## 代码现状

| 模块 | 已有实现 | 环境准备 |
| --- | --- | --- |
| 赛事与学习资源 | 目录、届次、来源正文、关联学习资源与公共页面 | 执行迁移并导入现行资料包 |
| 账号、组队与反馈 | 邮箱账号、招募申请、双方确认、成员管理、通知、举报与申诉 | 配置数据库；真实邮件需发件服务，内测可用已准备账号 |
| 科研 | 结构化介绍、招募筛选、详情、多来源链接；仓库含 120 条可导入的全国科研资料 | 导入资料并启用 `PUBLIC_RESEARCH_ENABLED` |
| AI | 四种模式、混合检索、赛事分析与找队友、来源引用、多轮问答及流式交互 | 配置模型服务与对应本地索引；索引缺失时的降级不等于语义检索已启用 |
| 联网搜索 | SearXNG 适配、页面读取和前端开关 | 单独运行搜索服务并配置地址；新前端默认关闭联网 |
| 内测 | Windows 隐藏启停、临时隧道、入口验证、账号准备与导出 | 使用本机私有配置；代码拉取不复制运行状态 |
