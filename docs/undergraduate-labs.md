## 网站呈现

“信息中心 → 项目招募”展示全部 6 条线索并提供关键词搜索；首页只预览 3 条，点击“查看全部”进入完整列表。卡片显示方向、本科参与依据、来源时间、核查日期和官方链接；未注明日期就明确显示未注明。旧公告保留原年份，不改写成“2026 正在招募”。联系渠道由官方原文提供，不收集学生简历、不代替学生发邮件。

本批是人工核查后的公共编辑内容，统一维护在 `backend/information_library/data/editorial.json` 的 `laboratories` 数组；`frontend/src/data/editorial.js` 只负责导入、导出，后台信息库读取同一文件。该 JSON 会随前端公开，**只能存放已经允许公开的内容，禁止放私有草稿、未公开信息、学生资料或密钥**。科研线索尚未纳入赛事自动采集；以后接在线编辑时复用已有 `research` 模型，不新增自由项目发帖或站内项目申请。

## 快讯维护

共享 JSON 的 `newsletters` 数组用于团队手动整理的首页快讯。当前为空，页面展示首期筹备状态。发布一条时填写 `id`、`title`、`date`、`summary`、`sourceUrl`；核查来源后填写真实核查日 `verifiedOn`（`YYYY-MM-DD`），未填写时不进入 AI 内部检索。原文可为团队有权公开的文章链接，不填虚构样例。通过任务分支修改、检查预览并合并，即可更新展示。后台[信息库](information-library.md)仅汇总查看，不提供在线富文本编辑或一键发布。

核查时曾遇到搜索摘要仍有招募文字、直接页面却已失效或正文不一致的结果，此类没有加入首页。后续维护以能直接打开的官方正文为准。
