# API 说明

本文区分已实现接口与待确定的业务约定。目前没有赛事查询、登录、招募或 AI 接口。

## 已实现：健康检查

| 项目 | 约定 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/v1/health/` |
| 本地地址 | `http://127.0.0.1:8000/api/v1/health/` |
| 身份要求 | 无需登录 |
| 请求参数 | 无 |
| 成功状态 | `200 OK` |
| 返回内容 | JSON |
| 数据库操作 | 无 |

成功响应：

```json
{
  "status": "ok",
  "service": "chuangxiang-backend"
}
```

`status` 表示这个接口成功响应；`service` 标识当前后端服务。该响应不表示数据库、邮件、AI 或业务模块已经可用。

浏览器打开根路径 `/` 会跳转到这个接口。可以在另一个 PowerShell 终端测试：

```powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:8000/api/v1/health/' -Method Get
```

接口不进行用户认证，不因为浏览器携带已有登录 Cookie 而查询用户表。提交 `POST` 等未支持的方法会返回 `405 Method Not Allowed`。
