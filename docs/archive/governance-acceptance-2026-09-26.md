# 举报与申诉验收

日期：2026-09-26。使用隔离 PostgreSQL 数据库、真实 Vue 页面和 Session/CSRF 请求。构造账号、限制和赛事仅存在于测试库，不进入正常网站。

| 操作 | 实际结果 |
| --- | --- |
| 游客查看赛事详情 | 只显示“登录后举报”，没有可提交的表单 |
| 普通账号登录，邮箱未核验且处于 24 小时业务限制 | 仍可展开固定原因举报表单并提交；新记录保存为待核实 |
| 查看“我的举报” | 仅展示本人刚提交的对象、说明和状态，不含处理人员隐私 |
| 发起申诉 | 服务端提供本人的限制记录，填写说明后成功保存为待复核 |
| 再次查看同一事项 | 标为已有待处理申诉，不能重复选择提交 |
| 退出后打开治理页面 | 显示登录提示，不展示此前内容 |
| 另一普通账号登录 | 举报、申诉均显示空记录，看不到前一账号提交内容 |

所检查浏览器标签没有 JavaScript error/warn。测试账号已退出，临时浏览器页面已关闭；测试环境的清理状态记录在团队进度。

后台处理、原管理员回避、CSRF、字段白名单、并发去重等由 PostgreSQL 专项验证，**21 项全部通过**（10.112 秒）。独立代码复核发现只读后台仍可能通过普通保存覆盖结论，已禁止普通详情写请求和 `save_model` 写回；新增测试证明旧实例不能覆盖复核结果，专用复核入口仍可用。

没有把后台专用复核表单说成经过本次浏览器点击验收；它由专项测试验证。本版处理反馈在本人记录页读取，不发送邮件；收到举报不会自动处罚，申诉成立也不自动撤销处分。
