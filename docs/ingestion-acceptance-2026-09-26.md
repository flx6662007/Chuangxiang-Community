## 哪些自动，哪些人工

| 工作 | 当前方式 |
| --- | --- |
| 到官网找新文章、复查旧通知 | 定时自动执行，限已接入的来源 |
| 提取、去重、保留版本、符合规则的新记录入库 | 程序自动执行 |
| 首次选来源、适配网页格式、修正解析规则 | 开发者维护，不是每次手工录入 |
| 已发布赛事的日期/人数/资格变化，原文缺项或冲突 | 进入待处理，由管理员核对 |
| AI | 当前关闭；以后可辅助复杂公告提取，仍需字段和原文依据校验 |

完整流程与代码入口见[赛事持续采集](ingestion-implementation.md)。本文件记录首批两来源的验收快照；后续新增来源以[团队进度](progress.md)为准。
