# 前端目录

本目录预留给电脑端网页。当前仓库尚未提交 Vue 工程，没有可运行的前端页面。

计划使用 Vue 3 和 Vite；前端负责人在此目录初始化工程后，补充实际依赖、Node.js 版本和启动命令。不要在仓库根目录或本目录下再次嵌套创建同名项目。

首次交付以赛事列表页面为目标：先按三方确认的数据格式使用明确标注的模拟数据开发，再接入后端接口。后端当前只有健康检查接口，不能提供赛事数据。

- [团队进度](../docs/progress.md)：记录交付状态、下一步和依赖。
- [API 说明](../docs/api.md)：查询当前可用接口和待确认约定。

赛事卡片是前端编写的组件，读取数据库中已有的数据后显示；普通浏览不调用 AI 生成卡片。
